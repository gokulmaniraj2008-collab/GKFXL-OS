# Experiment Design Engine

Designs bounded experiments that reduce uncertainty with minimal cost and risk.

## Experiment Structure

```text
Question:
Hypothesis:
Baseline:
Intervention:
Metric:
Success threshold:
Duration/sample:
Confounders:
Stop condition:
Result:
Decision:
```

## Rules

- Change as few variables as practical.
- Define success before observing results.
- Prefer reversible experiments.
- Record negative results.
- Do not move the goalposts after the outcome.
