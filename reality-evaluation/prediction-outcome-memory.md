# Prediction-to-Outcome Memory

Stores predictions together with later observations so future reasoning can learn from what actually happened.

## Memory Record

```text
Prediction ID:
Date:
Context:
Prediction:
Confidence:
Action taken:
Expected outcome:
Observed outcome:
Evidence:
Error:
Attribution:
Lesson:
Future adjustment:
```

## Learning Rule

Predictions must remain linked to outcomes. A prediction that is never checked against reality cannot become reliable learning data.

## Privacy Rule

Store only information necessary for the task. Never store secrets, credentials, private keys, or unnecessary sensitive information.
