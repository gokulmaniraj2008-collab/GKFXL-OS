# Confidence Calibration Engine

Aligns stated confidence with observed correctness over time.

## Principles

- Confidence is not evidence.
- High confidence + repeated failure requires recalibration.
- Low confidence + repeated success indicates under-confidence.
- Calibration should use outcome history, not intuition alone.
