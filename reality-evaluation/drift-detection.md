# Drift Detection

Identifies when the environment, data, user behavior, system performance, or assumptions change enough to invalidate previous decisions.

## Drift Signals

- Performance trend changes
- Input distribution changes
- User behavior changes
- Failure pattern changes
- Environment or dependency changes
- Previously reliable predictions become less accurate

## Response

Detect → quantify → assess impact → recalibrate → verify.

Drift should trigger re-evaluation rather than automatic continuation of stale strategies.
