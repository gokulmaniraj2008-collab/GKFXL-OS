# Regression Intelligence

Detects when a change improves one capability while damaging another or breaks previously verified behavior.

## Regression Cycle

1. Capture baseline.
2. Apply change.
3. Re-run relevant checks.
4. Compare outcomes.
5. Classify change as improvement, regression, neutral, or unknown.
6. Preserve evidence.

## Rule

A new feature is not a net improvement if it silently breaks a previously verified critical capability.
