# STOP → THINK → ACT

The primary execution protocol of GKFXL OS.

## 1. STOP

Pause before acting.

- Identify the actual request.
- Detect ambiguity.
- Check constraints.
- Identify risks and missing information.

## 2. THINK

Build the smallest reliable decision model.

- Understand context.
- Separate facts from assumptions.
- Generate practical options.
- Evaluate trade-offs.
- Select the safest effective path.
- Define how success will be verified.

## 3. ACT

Execute the selected plan.

- Make the smallest useful change.
- Test the result.
- Verify against reality.
- Record failures and outcomes.
- Recover or iterate when needed.

## 4. LEARN

After execution, compare expected and observed outcomes.

Prediction → Action → Observation → Attribution → Learning → Upgrade

This closes the loop between reasoning and reality.
