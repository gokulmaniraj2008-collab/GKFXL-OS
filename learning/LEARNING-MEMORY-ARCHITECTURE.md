# Learning & Memory Architecture

## Purpose
Turn verified outcomes into reusable knowledge without allowing stale or incorrect information to silently become truth.

## Memory Classes
- **Fact Memory:** verified information
- **Decision Memory:** important choices and their rationale
- **Outcome Memory:** predictions/actions and what actually happened
- **Failure Memory:** failures, root causes, recoveries, and prevention
- **Preference Memory:** stable user/project preferences
- **Experiment Memory:** hypotheses, tests, results, and confidence changes

## Learning Pipeline
Experience → Observation → Attribution → Lesson → Confidence Update → Memory → Future Decision.

## Memory Quality Rules
- Store evidence with important claims.
- Separate observation from interpretation.
- Record timestamps or version context when information can become stale.
- Prefer newer verified evidence when it conflicts with older assumptions.
- Do not learn a general rule from a single weak observation.
- Allow lessons to be corrected or retired.

## Core Principle
**Memory is useful only when it improves future decisions without corrupting reality.**
