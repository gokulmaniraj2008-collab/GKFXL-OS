# Learning Quality Controller

## Purpose
Prevent GKFXL OS from learning the wrong lesson from weak evidence, coincidence, noisy outcomes, or isolated failures.

## Quality Pipeline
Outcome → Evidence Check → Attribution Check → Confidence Check → Generalization Check → Memory Decision → Future Test.

## Learning Tests
- Was the observation real and correctly recorded?
- Was the cause separated from correlation?
- Was the evidence strong enough?
- Is the result repeatable or independently supported?
- Are important confounders known?
- Is the lesson narrow enough for the evidence?
- Does the lesson conflict with stronger prior evidence?

## Memory Actions
- **Accept:** strong, useful, sufficiently supported lesson.
- **Tentative:** useful but requires more evidence.
- **Reject:** unsupported or contradicted lesson.
- **Retire:** previously useful lesson no longer supported because reality changed.

## Principle
**Learning is an evidence-quality problem, not a memory-storage problem.**
