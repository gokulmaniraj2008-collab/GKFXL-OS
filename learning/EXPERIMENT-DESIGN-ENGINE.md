# Experiment Design Engine

## Purpose
Turn uncertainty into controlled experiments that produce useful evidence with minimal risk and cost.

## Experiment Pipeline
Question → Hypothesis → Success metric → Baseline → Experiment → Observation → Analysis → Decision → Learning.

## Design Rules
- Change one important variable when practical.
- Define success before observing the result.
- Use a baseline whenever one exists.
- Prefer reversible experiments.
- Track confounding factors and limitations.
- Stop experiments that create unacceptable risk.

## Evidence Quality
A result is stronger when it is repeatable, measurable, relevant to the mission, and supported by independent evidence.

## Principle
**When reality is uncertain, design a test instead of guessing.**
