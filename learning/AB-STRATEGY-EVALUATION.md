# A/B Strategy Evaluation

## Purpose
Compare competing strategies using real outcomes instead of preference or intuition.

## Evaluation Flow
Define alternatives → Set success metric → Establish baseline → Run comparable tests → Measure outcomes → Analyze differences → Check uncertainty → Select strategy.

## Rules
- Keep the comparison fair and relevant.
- Define the primary metric before testing.
- Record sample size, duration, and important conditions when applicable.
- Avoid declaring a winner from weak or noisy evidence.
- Consider safety, cost, reliability, and user impact alongside the primary metric.

## Decision States
- Winner supported by evidence
- No meaningful difference
- Mixed trade-off
- Inconclusive

## Principle
**Choose strategies from measured outcomes, not from which option sounds better.**
