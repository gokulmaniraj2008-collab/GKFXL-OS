# Reality Feedback Engine

## Purpose
Continuously feed observed real-world outcomes back into decisions, predictions, benchmarks, and future actions.

## Feedback Loop
Prediction → Action → Observation → Compare → Error → Explanation → Update → Re-test.

## Rules
- Prefer observed outcomes over expected outcomes.
- Record both success and failure signals.
- Preserve the context in which feedback occurred.
- Distinguish measurement error from genuine outcome change.
- Feed verified feedback into confidence, regression, drift, and learning systems.

## Principle
**Reality is the feedback signal that keeps the system aligned with what actually happens.**
