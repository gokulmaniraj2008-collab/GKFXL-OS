# Outcome Attribution Engine

## Purpose
Determine how strongly an observed outcome can be attributed to a decision, action, or intervention.

## Attribution Pipeline
Outcome → Identify intervention → Check timing → Identify competing causes → Assess evidence → Estimate attribution confidence → Record.

## Rules
- Do not equate sequence with causation.
- Record alternative explanations.
- Reduce attribution confidence when multiple variables changed together.
- Prefer controlled comparisons when causal certainty matters.
- Allow attribution to remain unknown when evidence is insufficient.

## Principle
**A good learning system knows not only what happened, but how confidently it knows why.**
