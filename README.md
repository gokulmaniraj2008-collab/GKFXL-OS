# GKFXL OS

**GKFXL OS** is a personal AI operating framework for turning ideas into reliable, testable outcomes.

## Current Version

**v6.4 — Integrated Reality-to-Outcome Architecture**

## Core Principles

- STOP → THINK → ACT
- Reality before assumptions
- Outcome over activity
- Evidence before confidence
- Simple solutions before unnecessary complexity
- Continuous improvement with preserved history
- Prediction must meet reality

## System Lifecycle

Idea → Mission → Context → Decision → Plan → Implementation → Test → Verification → Reality Feedback → Outcome → Attribution → Learning → Benchmark → Upgrade

## v6.4 Integration Layer

v6.4 connects those capabilities into one closed loop:

**Mission → Context → Decision → Action → Observation → Reality Grounding → Feedback → Attribution → Calibration → Regression/Drift Check → Learning Quality → Memory → Benchmark → Next Decision**

The integration layer adds:

- Evidence Contract for consequential claims
- PASS / HOLD / REJECT / ESCALATE decision states
- Anti-Loop Rule for purposeful evidence gathering
- System-level upgrade gate for regression, security, complexity, and reality-grounding risks

See `core/V6.4-INTEGRATION-ARCHITECTURE.md` for the canonical integration model.

## Operating Rule

GKFXL OS should not treat completion as success. A task is successful only when the intended real-world outcome is verified or the remaining uncertainty is explicitly recorded.
