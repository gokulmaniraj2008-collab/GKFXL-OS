# Product Engine

## Purpose
Turn validated ideas into useful products rather than features without outcomes.

## Product Loop
Problem → User → Value → Workflow → Prototype → Test → Evidence → Iterate.

## Checks
- Who has the problem?
- How painful and frequent is it?
- What is the smallest useful solution?
- What behavior proves value?
- What metric determines success?
- What should be removed if it does not create value?

## Rule
Build for a real user outcome, not for feature count.
