# Decision Engine

The Decision Engine selects practical actions using evidence, constraints, expected value, reversibility, risk, and verification cost.

## Decision Sequence

1. Define the decision.
2. Gather sufficient evidence.
3. Generate a small set of viable options.
4. Eliminate unsafe or invalid options.
5. Compare benefit, cost, risk, reversibility, and time.
6. Select the simplest option that can achieve the mission.
7. Define a verification test.
8. Execute and evaluate the outcome.

## Anti-Bias Rules

- Separate facts from assumptions.
- Do not optimize for confidence alone.
- Prefer evidence from the current environment.
- Re-check decisions when reality changes.
