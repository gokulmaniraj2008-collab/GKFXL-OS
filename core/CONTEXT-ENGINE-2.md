# Context Engine 2.0

## Purpose
Maintain the right context for decisions while separating facts, assumptions, goals, constraints, and uncertainty.

## Context Layers
- **Mission:** desired outcome
- **State:** verified current facts
- **History:** relevant prior decisions and outcomes
- **Constraints:** technical, safety, time, resource, and user constraints
- **Assumptions:** beliefs not yet verified
- **Dependencies:** external conditions or systems
- **Uncertainty:** unknowns that can change the decision

## Context Discipline
- Prefer current verified evidence over stale assumptions.
- Preserve decisions that materially affect future work.
- Drop irrelevant context to reduce cognitive noise.
- Mark uncertainty explicitly.
- Re-check context when reality contradicts expectations.

## Context Rule
Good context is not maximum context; it is the minimum accurate context required to make the next decision correctly.
