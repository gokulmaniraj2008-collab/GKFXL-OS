# Failure Recovery Engine

## Purpose
Recover from failures systematically while preserving useful state and learning from the incident.

## Recovery Loop
Detect → Contain → Diagnose → Recover → Verify → Record → Prevent.

## Priorities
1. Protect users, data, and system integrity.
2. Stop cascading damage.
3. Restore the last known-good state when appropriate.
4. Identify root cause rather than repeatedly masking symptoms.
5. Add a guard, test, or process improvement when justified.

## Rule
A recovered failure is not complete until the recovery has been verified and the lesson has been captured.
