# Project Health Score

## Purpose
Provide a compact reality-based view of project condition.

## Dimensions
Score each dimension from 0–10:
- Requirements clarity
- Implementation completeness
- Test coverage / verification
- Reliability
- Security
- Architecture quality
- UX / usability
- Deployment readiness
- Documentation
- Real-world outcome evidence

## Interpretation
- **90–100:** Strong / production-oriented
- **75–89:** Healthy with targeted gaps
- **50–74:** Needs focused improvement
- **Below 50:** High risk; stabilize before expanding

## Rule
The score is evidence-driven. Unknowns reduce confidence and must not be silently treated as success.
