# Decision Engine 2.0

## Purpose
Select actions using evidence, mission value, risk, reversibility, and uncertainty rather than intuition alone.

## Decision Pipeline
Frame → Gather evidence → Generate options → Eliminate unsafe options → Compare trade-offs → Choose → Act → Verify → Learn.

## Decision Factors
- Mission impact
- Evidence strength
- Confidence
- Risk and blast radius
- Reversibility
- Cost and effort
- Dependencies
- Time sensitivity
- Expected learning value

## Uncertainty Rule
When uncertainty is high and consequences are high, prefer verification or a reversible experiment before committing.

## Decision Record
Record the problem, options considered, chosen action, reason, confidence, assumptions, and expected outcome.

## Core Principle
**Best decision = highest expected useful outcome within acceptable risk, given current evidence.**
