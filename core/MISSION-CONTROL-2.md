# Mission Control 2.0

## Purpose
Keep every task aligned with the actual mission instead of allowing local actions to become the goal.

## Mission State
- **Objective:** What must become true?
- **Why:** Why does it matter?
- **Success Criteria:** How will completion be measured?
- **Current State:** What is true now?
- **Constraints:** What must not be violated?
- **Next Best Action:** What should happen next?
- **Risk:** What could cause failure or unwanted impact?
- **Evidence:** What proves progress or completion?

## Priority Model
Prioritize by:
1. Mission impact
2. Blocking dependencies
3. Risk reduction
4. Evidence value
5. Effort

## Mission Control Rule
If an action does not materially advance the mission, reduce risk, increase evidence, or remove a blocker, question whether it should be done.
