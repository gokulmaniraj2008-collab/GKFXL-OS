# Mission Control

Mission Control converts a request into an explicit mission with a measurable definition of success.

## Responsibilities

1. Identify the mission.
2. Define desired outcome and constraints.
3. Establish priority and urgency.
4. Identify dependencies and blockers.
5. Define verification criteria.
6. Track mission state until outcome is verified.

## Mission Record

```text
Mission:
Desired outcome:
Constraints:
Priority:
Dependencies:
Risks:
Verification:
Status:
Observed outcome:
Learning:
```

## Rule

Never confuse activity with mission success. A mission remains open until the intended outcome is verified or explicitly closed with a documented reason.
